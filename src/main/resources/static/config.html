全局配置

全局配置保存在服务器上，对所有使用者生效。

远程方式唤起链接

每行配置「远程方式名 → 唤起链接（自定义协议）」，例如：向日葵 → sunlogin://、Todesk → todesk://。
远程方式名必须与客户信息中填写的「远程方式」完全一致（一一对应），详情页才会出现「唤起」按钮；点击后唤起的是访问者本机的应用。
本页配置存于服务器、配一次所有人共用；若点击唤起时提示「没有注册协议」或进程启动但不弹窗，在对应电脑上点开下方的注册说明操作一次即可。

向日葵（sunlogin://）注册说明

向日葵国内版安装后通常已自动注册，无需操作，AweSun 等版本若无自动注册：
在本机开始菜单打开 PowerShell（普通权限即可），整段粘贴执行：
（脚本中的安装路径请按实际位置修改；写入的是当前用户注册表，不影响其他用户） 

$r=[Microsoft.Win32.Registry]::CurrentUser
$k=$r.CreateSubKey('Software\Classes\sunlogin')
$k.SetValue($null,'URL:Sunlogin Protocol')
$k.SetValue('URL Protocol','')
$k.Close()
$c=$r.CreateSubKey('Software\Classes\sunlogin\shell\open\command')
$c.SetValue($null,'"C:\Windows\explorer.exe" "D:\xiangrikui\AweSun\AweSun.exe"')
$c.Close()
Write-Output '注册完成'

完成后用 Win + R 输入 sunlogin:// 验证，向日葵能弹出即成功。

为什么用 explorer 包装：
部分远程软件（如 ToDesk、AweSun）启动时依赖工作目录，协议直接启动 exe 会出现「进程已启动但不弹窗」的情况。
用 explorer 启动与双击图标等效（工作目录自动为 exe 所在目录），可避免此问题。
若之前注册过直接启动的写法且不弹窗，把 command 值改为上面的 explorer 包装写法即可。

Todesk（todesk://）注册说明

Todesk 无官方 URL 协议，且直接启动时依赖工作目录，需要用 explorer.exe 包装（等同双击效果）。
在本机开始菜单打开 PowerShell（普通权限即可），整段粘贴执行：
（脚本中的安装路径请按实际位置修改；写入的是当前用户注册表，不影响其他用户） 

$r=[Microsoft.Win32.Registry]::CurrentUser
$k=$r.CreateSubKey('Software\Classes\todesk')
$k.SetValue($null,'URL:Todesk Protocol')
$k.SetValue('URL Protocol','')
$k.Close()
$c=$r.CreateSubKey('Software\Classes\todesk\shell\open\command')
$c.SetValue($null,'"C:\Windows\explorer.exe" "D:\ToDesk\ToDesk.exe"')
$c.Close()
Write-Output '注册完成'

完成后用 Win + R 输入 todesk:// 验证，Todesk 能弹出窗口即成功 （若只出现进程没有窗口，说明 command 里用了直接启动，请改用上面的 explorer 包装写法）。
